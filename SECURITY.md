# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report it privately through [GitHub security advisories](https://github.com/brano-osif/doklado-mcp/security/advisories/new). You will get a reply within a few days.

Useful details: what is affected, how to reproduce it and what an attacker could do with it. Do not include real API keys or customer data.

## Scope

This project handles Doklado API keys and SAPI+ credentials and can read and send invoices. Issues in how this server stores, logs or transmits those are in scope.

Problems in Doklado's own APIs or apps should go to Doklado directly.

## Supported versions

Only the latest release receives fixes.
